# 📚 Unidade 1 – "Visão Geral"

## 📖 Conteúdo

Nesta unidade foram apresentados os conceitos introdutórios da Engenharia de Requisitos, abordando sua motivação, importância e benefícios no desenvolvimento de software.

Também foram estudados:

- O papel da Engenharia de Requisitos no ciclo de vida do software;
- Os processos de requisitos na Engenharia de Software;
- Os papéis e perfis envolvidos na Engenharia de Requisitos.

## 📝 Atividades

### Atividade Prática – Levantamento de Requisitos

Foi realizada uma atividade prática sobre o levantamento de requisitos para um sistema de controle de alunos de uma escola.

A atividade envolveu:

- Identificação dos usuários do sistema;
- Elaboração de requisitos funcionais;
- Elaboração de requisitos não funcionais;
- Compreensão da importância do levantamento de requisitos antes do desenvolvimento de um software.

**Participantes:** Elton Eduardo Viana Lopes e Rafael Cardoso de Barros.
