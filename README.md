# 📚 Engenharia de Requisitos

Repositório destinado ao armazenamento de atividades, materiais e conteúdos desenvolvidos durante a disciplina de **Engenharia de Requisitos**, do curso de Engenharia de Software.

O repositório reúne os estudos realizados ao longo do semestre, documentando conceitos, exercícios, atividades práticas e projetos relacionados à disciplina.

## 📖 Sobre o repositório

Este repositório apresenta os conteúdos estudados em cada unidade da disciplina, reunindo materiais e atividades desenvolvidos durante as aulas.

Os arquivos estão organizados em pastas, permitindo consultar os assuntos abordados e acompanhar o percurso de aprendizagem em Engenharia de Requisitos.

## 🔗 Repositórios externos e conexões com as unidades

Além dos materiais e atividades desenvolvidos ao longo da disciplina, este repositório também reúne referências a projetos complementares disponíveis no GitHub, relacionados aos conteúdos estudados em diferentes unidades.

### 📊 FlowOps — Sistema de Gestão de Projetos Ágil

🔗 [Acessar repositório FlowOps](https://github.com/gabrielmarciano-dev/sistema-de-gestao-de-projetos-agil)

O projeto **FlowOps** possui conexão com os conteúdos abordados na [**Unidade 3**](./Unidade3) e na [**Unidade 4**](./Unidade4), complementando os estudos sobre Engenharia de Requisitos, análise de necessidades, definição de requisitos e priorização.

### 🔗 Conecta

🔗 [Acessar repositório Conecta](https://github.com/GabrielMarcianoarante/AulaEngRequisito)

O projeto **Conecta** está relacionado aos conteúdos da [**Unidade 5**](./Unidade5), servindo como referência complementar para os estudos de **Elicitação de Requisitos e Modelagem de Sistemas**.

Esses projetos complementam o percurso de aprendizagem da disciplina, conectando os conceitos estudados em sala de aula às suas aplicações práticas em projetos de software.

## 🎯 Objetivos

- 📚 Compreender os fundamentos da Engenharia de Requisitos;
- 👥 Identificar as necessidades dos stakeholders;
- 📝 Desenvolver e documentar requisitos de software;
- ⚙️ Compreender requisitos funcionais e não funcionais;
- 📊 Aplicar técnicas de priorização de requisitos;
- 💻 Estudar características de qualidade de software;
- 📐 Desenvolver modelos para representação de sistemas;
- 🧠 Relacionar conceitos teóricos com aplicações práticas.
